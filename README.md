El caso elegido consiste en mejorar el proceso de revision de datos de los postulantes de una autoescuela. El objetivo es reducir el tiempo necesario para buscar, verificar y corregir informacion antes de elaborar las actas de examen

El proyecto se basa en la optimizacion del proceso de revision de postulantes de la Auto Escuela Concordia, el objetivo es reducir el tiempo necesario para buscar, verificar y corregir los datos de los postulantes antes de elaborar las actas del examen y las listas correspondientes.
